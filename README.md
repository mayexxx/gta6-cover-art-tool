# Vice City Cover Studio

An offline cover maker for turning your photos into neon-soaked, multi-panel stories.

Run `node main.ts` with Node 22 to write the entry to `/output`; set `MAKEFUN_OUTPUT_DIR` to choose another output directory. To use the editor locally, run `node serve.ts` and open the printed address.
